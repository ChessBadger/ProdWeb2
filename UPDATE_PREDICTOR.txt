EASY OWNER UPDATE: double-click UpdatePredictor.cmd in this Website folder.
1. Select new timesheets (files or a folder) and/or an updated production workbook. Choose Current crew only to update the roster, or Full/current + former for historical backfill that preserves the roster. Click Import selected files. A recoverable local backup is made first; originals and all correction versions stay local.
2. Review results and the current roster. Identical imports are skipped. Invalid files are reported; successfully imported files are retained. Unmatched attendance remains available in local history/mapping tools rather than being fabricated into complete model history.
3. Check the public-data review box and click Publish current changes. This works without new files for code/UI updates. It builds this week's plan, verifies allowlists and actual Git bytes, stages only pages_repository approved files, commits meaningful changes and pushes main to ChessBadger/Production-Predictor using your existing Git authentication.
A pushed commit is not yet a deployed site. Use Check deployment or GitHub Actions; failed deployments remain visible and the site may show its previous version. No force pushes, remote changes or credential/billing changes are made. Staged user work and newer remote main changes require review in your Git client; they are never overwritten. If a push fails, the local commit/history remain safe and Publish current changes can retry after resolving the Git error.
Leave the launcher console open while working. Reopening the launcher reuses this local profile. For a restored profile, UpdatePredictor.cmd accepts its directory as an optional first argument. The service binds 127.0.0.1 only; upload/publish endpoints require the current local page token and reject unexpected origins.
Public scope remains current employee names and derived model/productivity data, downloadable independently of the interface login. Raw exports, timesheets, former identities, archives, backups, local tools and research are excluded. Visitors have no upload controls.

If an older local app is already running, finish its imports and close its console once before opening the updated launcher. The launcher does not kill an existing app or interrupt its imports.
